# Supply Chain Analysis: Dataset and Python Analysis

## Overview
In this project, we analyze a company's supply chain using a dataset from a Fashion and Beauty startup. The dataset includes data on various stages of the supply chain such as sourcing, manufacturing, transportation, inventory management, sales, and customer demographics. We will use Python to explore and analyze this data and uncover valuable insights.

You can download the dataset from [here](#).

## Dataset Structure
The dataset consists of the following columns:

- **Product type**: Type of product (e.g., haircare, skincare)
- **SKU**: Stock Keeping Unit (unique identifier for each product)
- **Price**: Price of the product
- **Availability**: Stock availability of the product
- **Number of products sold**: Total units sold
- **Revenue generated**: Revenue generated from product sales
- **Customer demographics**: Demographics of the customers purchasing the product
- **Stock levels**: Current stock in the inventory
- **Lead times**: Time taken for products to be manufactured
- **Order quantities**: Number of units ordered
- **Shipping costs**: Cost of shipping for each product
- **Manufacturing costs**: Cost incurred for manufacturing each product
- **Defect rates**: Percentage of defective products in the supply chain
- **Transportation modes**: Modes of transportation used for shipping
- **Costs**: Total costs associated with the product

## Getting Started

### Import Necessary Libraries
To begin, we import the necessary Python libraries and load the dataset:

```python
import pandas as pd
import plotly.express as px
import plotly.io as pio
import plotly.graph_objects as go

pio.templates.default = "plotly_white"
data = pd.read_csv("supply_chain_data.csv")
print(data.head())
```

### Dataset Description
We can view the basic descriptive statistics of the dataset:

```python
print(data.describe())
```

### Initial Analysis

1. **Price vs. Revenue Generated**: To understand the relationship between product price and revenue generated:

```python
fig = px.scatter(data, x='Price', y='Revenue generated', color='Product type', hover_data=['Number of products sold'], trendline="ols")
fig.show()
```

2. **Sales by Product Type**: A pie chart to visualize sales distribution by product type:

```python
sales_data = data.groupby('Product type')['Number of products sold'].sum().reset_index()
pie_chart = px.pie(sales_data, values='Number of products sold', names='Product type', title='Sales by Product Type', hole=0.5, color_discrete_sequence=px.colors.qualitative.Pastel)
pie_chart.update_traces(textposition='inside', textinfo='percent+label')
pie_chart.show()
```

3. **Revenue by Shipping Carrier**: A bar chart to visualize total revenue generated by each shipping carrier:

```python
total_revenue = data.groupby('Shipping carriers')['Revenue generated'].sum().reset_index()
fig = go.Figure()
fig.add_trace(go.Bar(x=total_revenue['Shipping carriers'], y=total_revenue['Revenue generated']))
fig.update_layout(title='Total Revenue by Shipping Carrier', xaxis_title='Shipping Carrier', yaxis_title='Revenue Generated')
fig.show()
```

4. **Average Lead Time & Manufacturing Costs**:

```python
avg_lead_time = data.groupby('Product type')['Lead time'].mean().reset_index()
avg_manufacturing_costs = data.groupby('Product type')['Manufacturing costs'].mean().reset_index()
result = pd.merge(avg_lead_time, avg_manufacturing_costs, on='Product type')
result.rename(columns={'Lead time': 'Average Lead Time', 'Manufacturing costs': 'Average Manufacturing Costs'}, inplace=True)
print(result)
```

```python
defect_rates_by_product = data.groupby('Product type')['Defect rates'].mean().reset_index()
```

2. **Defect Rates by Transportation Mode**:

```python
pivot_table = pd.pivot_table(data, values='Defect rates', index=['Transportation modes'], aggfunc='mean')
```
